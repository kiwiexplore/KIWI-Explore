# KIWI Explore

## Project Overview

KIWI Explore is a long-term AI Operating System being built from scratch.

The goal is not just another chatbot.

The goal is to build an intelligent modular operating system capable of assisting with:

- Exploration
- Research
- Business Management
- Robotics
- Automation
- Space Technologies
- AI Agents
- Knowledge Management

The dashboard is called KIWI HQ.

The central AI entity is called KIWI.

---

## Current Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Zustand (state management — chosen because CommandEngine and future
  services need to read/write shared state from outside React
  components, which plain React Context cannot do)
- CSS
- Git
- GitHub

Development Machine:

- MacBook Air M5
- VS Code
- Node.js
